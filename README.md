# Incremental Reading

An Anki add-on concept for incremental reading workflows: break source material into manageable notes, revisit excerpts over time, and turn useful passages into spaced-repetition cards.

## Project Status

Early project scaffold. The repository currently documents the plugin idea and intended workflow.

## Intended Workflow

1. Import or paste reading material into Anki.
2. Split long text into smaller reviewable excerpts.
3. Promote important excerpts into cards or cloze-style prompts.
4. Review reading material gradually alongside normal spaced-repetition cards.

## Planned Features

- Queue long-form reading material inside Anki
- Convert passages into reviewable notes
- Track reading progress across excerpts
- Support card creation from highlighted text
